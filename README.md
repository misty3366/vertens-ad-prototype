# SunADS

SunADS is an interactive product prototype for AI-powered local-store marketing. It helps offline businesses recreate winning ads, localize the offer, generate image and video variants, and learn which creatives produce visits, bookings and qualified conversations.

## Product modules

- **Home** — a four-step path from winning video to store-visit campaign.
- **Agent** — conversational AI image, video, avatar, voice and product-editing tools.
- **Ad Flow** — viral-clone discovery and an infinite workflow canvas powered by React Flow.
- **Projects** — generated campaign assets and publishing handoff.
- **Templates** — proven local-business video structures across 16 industries.
- **My Brand** — offers, presenters, voices and reusable brand assets.
- **Creative Service** — done-for-you video outsourcing with playable samples and a production brief flow.
- **Performance** — creative, visit, booking and qualified-lead reporting.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Validate

```bash
npm run build
npm run test:sites
```
