# SunADS

SunADS is an interactive product prototype for AI-powered ad creation and done-for-you video production for overseas home-improvement retailers and showrooms.

## Product modules

- **Home** — task discovery and campaign shortcuts.
- **Agent** — conversational AI image, video, avatar, voice and product-editing tools.
- **Ad Flow** — viral-clone discovery and an infinite workflow canvas powered by React Flow.
- **Projects** — generated campaign assets and publishing handoff.
- **My Brand** — products, presenters, voices and reusable brand assets.
- **Studio** — done-for-you video outsourcing with playable samples and a production brief flow.
- **Performance** — creative and showroom-lead reporting.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Validate

```bash
npm run build
npm run test:sites
```

## Technology

- React 19
- Vite 6
- React Flow
- Phosphor Icons
